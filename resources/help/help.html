Newton Connection Help

Newton Connection backs up your Newton MessagePad or eMate, restores it, installs packages, and moves information between the Newton and this computer. It connects to Newton OS 2 and Newton OS 1 devices, and to the Einstein emulator.

Connecting a Newton device

Newton Connection waits for a Newton device all the time it runs. On the Newton, open the Dock app (Connection on Newton OS 1), choose how to connect, and tap Connect. When the Newton is docked, its window opens with its backup.

TCP/IP (ethernet or wireless). The Newton needs the Newton Internet Enabler (NIE), a driver for its network card, and a Dock with a TCP/IP option (for example Dock_TCP or EthernetDock). Enter this computer's address in the Dock app. Newton Connection listens on port 3679; another port can be set in the Preferences (Connection). Your firewall must let Newton Connection accept connections.

Serial. Connect the Newton's serial cable to a serial port or a USB serial adapter. Choose the port in the Preferences (Connection). The Dock app connects at 38,400 bps; higher speeds need a package on the Newton (for example Ser115200) and the same speed in the Preferences. Both ends must use the same speed.

Einstein. On macOS, Newton Connection also listens on Einstein's serial port; elsewhere connect Einstein over TCP/IP.

Password. A password in the Preferences (General) is asked of every Newton that connects. It isn't the Newton's own PIN.

Backing up

Each Newton device has a backup on this computer, made the first time it connects, named by its serial number. To back up, click Back Up in the device view, or choose Newton > Back Up. You can also start a backup on the Newton: Dock's Backup. The toolbar shows the progress; Cancel stops it.

Backups are synchronized: what changed on the Newton comes into the backup, and what you changed in the backup (entries deleted or imported without the Newton) goes to the Newton. If a backup would delete more than a few entries on the Newton, Newton Connection asks first.

The Preferences can have Newton Connection set the Newton's date and time when it connects, and back it up when it docks by itself.

A backup is an ordinary file: copy it somewhere to keep the Newton's state of that day.

Restoring

Restoring replaces information on the Newton device with the information in its backup. Click Restore in the device view (or choose Newton > Restore), choose the Newton's store to restore and the backed up store to restore it from, the information (apps) and the packages, and click Restore. Only what you choose is replaced: if you restore Names, the Notes on the Newton stay as they are. When it is done, the Newton asks to restart. A PIN is not restored.

A card's backup can be restored to a card, not to the internal store.

Installing packages

Packages add applications, books and updates to a Newton device. Package files end in .newtonpkg or .pkg. Choose Newton > Install Package, or drop package files on the docked Newton's window. On the Newton, Dock's Install can also browse this computer's folders and install from there. A package that is on the Newton already is replaced only if you say so.

Using this computer's keyboard

Select Keyboard in the sidebar of the docked Newton's window. Set an insertion point on the Newton, click the keyboard area, and type: the text goes to the Newton. Edit > Paste, or dropping text on the area, sends text from elsewhere. Starting the keyboard on the Newton (Dock's Keyboard) shows this view too.

Transferring information

Export. Select entries in a soup (or a soup, or an app in the sidebar) and choose File > Export. Names become vCards, Dates iCalendar files, Notes and Newton Works documents RTF (with their drawings and ink), drawings PNG images, recordings sound files, packages package files; other entries are written as NewtonScript text. The inspector (View > Inspector) shows an entry as it would be exported.

Import. Choose File > Import, or drop files on a window: vCards go to Names, iCalendar files to Dates, text and RTF to Notes. When the Newton is docked, the entries go to it at once.

Between backups. Drag entries from one backup's window to another's: they are copied into the soups of the same names.

Taking a screenshot

Select Screenshot in the sidebar of the docked Newton's window. The Dock slip goes away; arrange the Newton's screen and click Take Screenshot. Save writes it as a PNG image, Copy puts it on the clipboard. Screenshots need the Toolkit app on the Newton (it comes with the Newton Toolkit).

Working without a Newton device

Open any backup with File > Open, or from the list in the window that waits for a Newton. You can browse it, export from it, delete entries and import files. Entries you delete or import are deleted on, or added to, the Newton when you next back it up.

Newton OS 1 devices

Before a Newton OS 1 device connects, choose what it is to do in the Newton > NewtonOS 1 Session menu: Sync (back up), Restore, or Install Package. That is done once it connects, and then it is disconnected.

Saving the ROM and memory cards

Newton > Dump ROM saves the docked Newton's ROM into a file; a dump that was stopped can be resumed. Newton > Dump Card saves the memory cards in its slots (their CIS, attribute and common memory) into a folder. Both need Newton OS 2.

Where Newton Connection keeps its files

Backups (.newtondevice files):

  • macOS: ~/Library/Application Support/Newton Connection
  • Windows: %APPDATA%\Newton Connection
  • Linux: ~/.local/share/newton-connection

The log, if the Preferences save it:

  • macOS: ~/Library/Logs/NewtonConnection.log
  • Windows: %LOCALAPPDATA%\Newton Connection\NewtonConnection.log
  • Linux: ~/.local/state/newton-connection/NewtonConnection.log
